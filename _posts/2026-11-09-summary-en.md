### [KetchUp: Open-Source SketchUp Alternative Built with Rust and WebGPU](https://ketchup3d.github.io/app/) ⭐️ 7.0/10

KetchUp is an open-source, browser-based alternative to SketchUp built with Rust and WebGPU. The supplied item identifies it as a 3D modeling tool but does not detail feature parity, licensing terms, or platform support beyond the browser. Early user feedback points to missing trackpad controls, with one commenter saying the app appears mouse-only, so it should be treated as an early-stage tool rather than a drop-in SketchUp replacement.

hackernews · dcoulmbe · Nov 8, 22:35 · [Discussion](https://news.ycombinator.com/item?id=50418176)

**「Background」** SketchUp is the commercial 3D modeling application that KetchUp is positioned as an alternative to. KetchUp&\#x27;s GitHub describes it as free, open-source modeling software built with Rust, WebAssembly, and WebGPU that runs in a browser or on desktop. Its project page focuses the tool on woodworking and furniture design, including shelves, tables, cabinets, and workbenches with exact measurements.

**「What it means for early adopters」** Because KetchUp runs in the browser on WebGPU rather than as an installed desktop application, trying it requires no download or license, but access is limited to users on browsers with working WebGPU support. One commenter reports that navigation is mouse-only, with no trackpad gestures for pan, zoom and orbit, so laptop users without a mouse or the familiar SketchUp modifier-key workflow may not be able to model comfortably until input handling is expanded.

**「Community Discussion」** Commenters welcomed an open-source SketchUp successor, with one 3D-printing hobbyist saying SketchUp 8 was the easiest modeler to learn and hoping KetchUp fills that gap. The main concrete usability complaint was the lack of trackpad support; another thread debated whether users should build custom tools with coding agents instead of learning general-purpose software.
